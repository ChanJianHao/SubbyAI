# Changelog

## 1.0.0

First SubbyAI release.

- Live original-language captions with independent local or optional remote translation.
- Simple settings, Advanced Mode and hardware-aware Fast/Balanced/Accurate profiles.
- Skippable setup with hardware recommendations and a real audio meter.
- Original Mochi artwork, Sakura/Ocean accents and light/dark/system themes.
- Nine subtitle styles and configurable display placement, typography and readability.
- Revision-pinned speech models, validated language packs and cancellable downloads.
- Consent-based compatible speech servers and endpoint-bound OS credential storage.
- Opt-in searchable transcript history, exports and optional transcript assistance.
- Bounded queues, visible overload diagnostics and graceful device/failure recovery.
- Per-user Windows installer, portable distribution and architecture-specific macOS bundles.

V1 binaries are unsigned; installation guides explain the platform prompts.
